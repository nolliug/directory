About The gTLD Directory.

Learn about The gTLD Directory, an independent discovery resource for organisations serving the global domain name industry.

The gTLD Directory is an independent discovery resource designed to help people identify organisations and specialists active across the global domain name industry.

The directory covers registry operations, registrar services, registry technology, consultancy, legal and intellectual property, DNS infrastructure, escrow, trust services and domain marketing.

Who the directory serves

It is intended for registry operators, registrars, brand owners, new gTLD applicants, legal and trademark professionals, DNS specialists, consultants and other participants in the domain name ecosystem.

How to use the directory

Use search and category pages to discover organisations, then consult each organisation’s own website and materials when evaluating its services. Directory inclusion is informational and does not constitute endorsement.

For corrections, questions or listing enquiries, contact contact@gtld.directory.
